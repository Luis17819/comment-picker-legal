Política de Privacidade - Comment Picker

Última atualização: 1º de outubro de 2026

Esta Política de Privacidade descreve como o Comment Picker coleta, utiliza e trata informações quando usuários utilizam o serviço para realizar sorteios a partir de publicações do Instagram.

1. Informações coletadas

Ao conectar uma conta profissional do Instagram ao Comment Picker, o aplicativo poderá acessar, mediante autorização do usuário e de acordo com as permissões concedidas pela API da Meta, informações necessárias para o funcionamento do serviço.

Essas informações podem incluir:

  • Informações básicas da conta profissional do Instagram;
  • Identificadores da conta;
  • Publicações da conta conectada;
  • Comentários das publicações selecionadas;
  • Nome de usuário ou identificador dos participantes, quando disponibilizado pela API;
  • Conteúdo, data e horário dos comentários;
  • Tokens de acesso necessários para comunicação autorizada com a API do Instagram.

2. Como utilizamos as informações

As informações são utilizadas para permitir que o usuário:

  • Conecte sua conta profissional do Instagram;
  • Visualize suas publicações;
  • Carregue os comentários de uma publicação;
  • Identifique participantes;
  • Elimine participações duplicadas quando aplicável;
  • Realize sorteios aleatórios;
  • Registre informações necessárias para apresentação e auditoria do resultado.

Os dados obtidos através da API do Instagram não serão vendidos.

3. Compartilhamento de informações

O Comment Picker não vende nem comercializa informações obtidas através das contas do Instagram conectadas ao serviço.

Informações poderão ser processadas por prestadores de infraestrutura necessários para a operação do serviço, como serviços de hospedagem e banco de dados, sujeitos às medidas de segurança aplicáveis.

4. Armazenamento e segurança

Adotamos medidas técnicas e organizacionais razoáveis para proteger as informações processadas contra acesso não autorizado, alteração, divulgação ou destruição indevida.

Os dados serão mantidos somente pelo período necessário para fornecer as funcionalidades do serviço ou cumprir obrigações legais aplicáveis.

5. Tokens e acesso ao Instagram

A conexão com o Instagram utiliza os mecanismos de autorização disponibilizados pela Meta. O Comment Picker não solicita nem armazena a senha do Instagram do usuário.

Tokens de acesso eventualmente armazenados serão utilizados exclusivamente para realizar operações autorizadas pelo usuário através da API do Instagram.

6. Exclusão de dados

O usuário poderá solicitar a exclusão dos dados associados à sua utilização do Comment Picker.

Após uma solicitação válida, os dados serão excluídos ou anonimizados, exceto quando sua conservação for necessária para cumprimento de obrigação legal.

7. Serviços da Meta

O Comment Picker utiliza APIs disponibilizadas pela Meta para integração com o Instagram. O uso do Instagram também está sujeito aos termos e políticas disponibilizados pela Meta e pelo Instagram.

8. Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada para refletir alterações no serviço, nas APIs utilizadas ou nos requisitos legais.
