Exclusão de Dados - Comment Picker

Usuários do Comment Picker podem solicitar a exclusão dos dados associados à sua utilização do serviço.

Como solicitar a exclusão

Envie um e-mail para luishenriqueretore.rodrigues@gmail.com com o assunto "Exclusão de dados - Comment Picker".

Informe no pedido a conta do Instagram associada ao Comment Picker para que seja possível identificar os dados relacionados à solicitação.

O que será excluído

Após a identificação e validação da solicitação, os dados associados ao usuário armazenados pelo Comment Picker serão excluídos ou anonimizados, salvo quando sua conservação for necessária para cumprimento de obrigação legal.
